# JSON and NuGet Assignment

Console application for reading JSON and XML data in C# with the .NET class library and the `Newtonsoft.Json` NuGet package.

## How to Run

```bash
dotnet restore
dotnet run
```

## Version History

- Created `Data/user.json` manually.
